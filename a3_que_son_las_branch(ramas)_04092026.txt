tema: Que son las bifurcaciones
==========================

Las ramas o branch son simplemente especios de trabajo independientes
que permiten realizar cambios sin afectar el proyecto principal. Cada vez
que se crea una los commit estaran asociados a dicha rama.

Tecnicamente son:
Punteros móviles que apuntan a un commit específico. Nos
permiten desviar el flujo de trabajo principal para crear
funcionalidades o arreglar errores en aislamiento.


En lugar de duplicar los archivos fisicamente lo que hace realmente git
es crear una referencia  ligera para que los proximos cambios se guarden en este nuevo 
flujo sin alterar la rama principal.

--------------------------------------------
COMANDOS BASICOS
--------------------------------------------

1. Como crear una rama
	git branch <nombre_de_la_rama>

2.Como moverse entre ramas:
	git switch <nombre_de_la_rama>

3.Como hacer los dos comandos anteriores al mismo tiempo:
	git switch -c <nombre_de_la_rama>
	
	tambien:
	git checkout -b <nombre_de_la_rama>
4.Como cambiar el nombre de un rama:
	4.1. Si estamos en una rama diferente
		git branch -git branch -m nombre-antiguo nuevo-nombre
	4.2 Si estamos en la misma rama
		git branch -m nuevo-nombre
