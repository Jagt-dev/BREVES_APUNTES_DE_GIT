tema: El famoso archivo readme.md

---------------------

El archivo readme es el documento que presenta las funcionalidades y documenta nuestro 
repositorio. Su contenido es escrito con un lenguaje llamado "Mark Down" que es basicamente
texto plano pero implementa una sintaxis para hacer más presentable el contenido.


Una pagina para poder generar markdown y ver su resultado es:

https://pandao.github.io/editor.md/en.html


En la pagina se encuentra un panel para insertar sintaxis de markdown y en el otro 
para ver su resultado.

Mejorar el archivo readme del repositorio actual.
